# Lipids in cell signalling
- Phospholipids make up
	- the lipid bilayer 
	- intracellular second messengers 
	- Precursors for eicosanoids - inflammatory mediators
- Cell-cell communication 
	1. Synthesis of signal
	2. Release of signalling molecule
	3. Transport to target cell
	4. Detection of signal by receptor
	5. Change in cellular processes
	6. Removal of signal/desensitisation
	- Signals can act at short or long range 

## Extracellular molecule types
### Long range
- Endocrine
	- Hormone -> bloodstream -> distal target cell
- Neurotransmission
	- Neuron -> neuron -> neuron -> etc -> target cell

### Short range
- Paracrine ![[Pasted image 20260209153858.png]]
	- Only affects target cells in close proximity 
- Autocrine ![[Pasted image 20260209153923.png]]
	- Signal affects self 
- Membrane-bound proteins
	- ![[Pasted image 20260209153945.png]]
	- Signals adjacent cell 
	- Eg APC -> T cells

- Multiple types of signalling can occur simultaneously 
	- Eg insulin
	- Autocrine - inhibits β-cells from producing more
	- Paracrine - inhibit glucagon secretion from α-cells
	- Endocrine - encourage glucose uptake

## Signal transduction 
- Most things act on extracellular receptors -> production intracellular chemicals
	- Exception - lipid soluble molecules -> intracellular receptors
	- ![[Pasted image 20260209154236.png]]
- Types of receptors
	- Ligand gated ion channels
	- G protein coupled receptors 
	- Kinase linked receptors - phosphorylates proteins -> cellular effects
	- Nuclear receptors - lipid enters -> intracellular receptor -> nucleus -> effects
		- Eg cortisol ![[Pasted image 20260209154605.png]]
- Signal effect is done either via altering protein functions, or altering protein synthesis (transcription/translation) to create new, different proteins - both create altered cell behaviour ![[Pasted image 20260209154518.png]]


## Phospholipid signalling
- Inositol phospholipid signalling pathway 
	- Phosphatidylionsitol 4,5-bisphosphate (PIP2) - found in lipid bilayer 
	- Substrate for enzyme phospholipase C (PLC)
		- Creates inositol 1,4,5 trisphophate ([[Smooth Muscle Contraction|IP3]]) and diacyglycerol (DAG) 
		- IP3 activates Ca channels in the SR -> Ca enters the cytosol
	- ^ Activated by g protein ![[Pasted image 20260209154842.png]]
		- Ca -> activates PKC - Activated PKC then phosphorylates other things
			- Ca also activates other cellular pathways (contraction, etc)
		- PKC (Protein Kinase C) 
			- 3 domains (C1, 2, 4) and pseudosubstrate to self-inhibit activity
			- C1 - binds to DAG -> causes pseudosubstrate to detach -> can phosphorylate stuff now
			- C2 - binds to Ca
			- C4 - catalytic site

## Eicosanoids
- Local hormones - autocrine/paracrine,  rapidly degraded so not transported to distal sites
	- Eicosa - 20 carbon backbone
	- Enoic - double bonds 
	- Main precursor is arachidonic acid - 20C with 4 double bonds (20:4) - [[Introduction to Enzymes]] ![[Pasted image 20260209160021.png]]
- 3 main types
	- Prostaglandins
		- Regulates vasoconstriction/dilation, pain, platelet aggregation - contrasting effects -> depends on receptor bound
	- Thromboxanes
		- Synthesised in platelets 
		- Prothrombotic properties - platelet aggregation
		- Is also a vasoconstrictor
		- TXA - active
		- TXB - inactive 
			- TXA + H2O -> TXB 
		- Short lived - autocrine/paracrine
	- Leukotrienes
		- Synthesised in WBC's
		- Trienes - conjugated 3 double bonds tgth
		- Some contain cysteine inside -> associated with anaphylaxis 
		- Immune response, also implicated in asthma and allergy
- Biosynthesis ![[Pasted image 20260209160446.png]]
	- Cleaved from phospholipid - leaves behind platelet activating factor (PAF)
		- Done by phospholipase A2 (PLA2) 
			- Phospholipases are named after the chain position they cleave ![[Pasted image 20260209160232.png]]
				- Eg A1/A2 - first 2 carbons of the backbone
				- C/D - others ┐(ツ)┌ 
			- Can be stimulated by various things, eg serotonin receptors, increased Ca etc
		- PAF's
			- Platelet aggregation, vasoconstriction, inflammation, and immune response
	- Then different enzymes -> different eicosanoids 
		- Clyclooxygenase (COX) -> prostaglandins and thromboxanes
		- Lipoxygenase -> leukotrienes
	- ![[Pasted image 20260209161244.png]]

### Regulation 
- Non steroidal anti inflammatory drugs (NSAIDs)
	- Inhibit cyclooxygenases -> inhibits formation of prostaglandins and thromboxanes 
	- Eg aspirin and ibuprofen 
		- Ibuprofen blocks the hydrophobic channel by which arachidonate enters the cyclooxygenase active site
		- Aspirin ([[Introduction to Enzymes]]) acetylates a serine hydroxyl group near the active site - irreversible, but resynthesis of COX would restore activity
			- However - platelets don't have nuclei - no resynthesis - very long effect of aspirin on platelets -> long anti-clotting effect
